# PortaldotHack

## Overview
PortaldotHack is a modular low-code orchestration platform designed to streamline developer workflows and data synthesis in the Polkadot ecosystem, leveraging Relevance AI and NotebookLM.

## Tech Stack & Architecture
- **Orchestration:** Relevance AI (Multi-agent workflows)
- **Knowledge Synthesis:** NotebookLM
- **Version Control & Docs:** GitHub, Substack, DEV.to, Netlify

## Portaldot V3 Testnet Configuration
To connect and interact with the Portaldot V3 testnet environment, use the following network parameters:
- **WebSocket RPC:** `wss://test-node-v3.portaldot.dev`
- **EVM Endpoint:** `https://test-evm-rpc-v3.portaldot.dev`
- **Chain ID:** `420420777`

## Setup & Deployment
1. Clone the repository: `git clone https://github.com/rcortez056-spec/PortaldotHack.git`
2. Configure your environment variables using the Portaldot V3 testnet endpoints provided above.
3. Ensure the Otari gateway environment variables are configured via otari.env.
